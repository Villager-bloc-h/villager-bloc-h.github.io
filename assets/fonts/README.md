# Mojangles.woff

站名与页面大标题使用的 Minecraft 风格字体。

- 字体：Mojangles
- 用途：`.brand-name`、`#profile-title`
- 来源：[CDNFonts / Minecraft](https://fonts.cdnfonts.com/css/minecraft-6)
- 版权：归 Mojang Studios 所有，不包含在项目的 MIT 许可内

替换字体时保持文件名 `Mojangles.woff` 不变即可；如需使用其他字体，同时修改 `assets/style.css` 中的 `@font-face` 和 `--font-minecraft`。
